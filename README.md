# رحلة لغتي 🦅

لعبة تعليمية لمنهج **لغتي — الصف الثاني الابتدائي، الفصل الدراسي الأول**: كل درس من الكتاب تحوّل إلى ألعاب قصيرة (استماع، قراءة جهرية مع تسجيل الصوت، مفردات، ظواهر لغوية، إملاء، خط، تعبير)، مع لوحة متابعة لوليّ الأمر.

- الصفحة: `index.html` (ملف واحد مستقل).
- المزامنة بين جهاز الطفلة وجهاز وليّ الأمر عبر Firebase برمز عائلة سري.
- كل النصوص داخل اللعبة أصلية ومكتوبة خصيصًا لها.
